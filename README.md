# MATH DOORS — 괴물 3D 업그레이드 (2차)

이 버전은 **이전 3D 소품 업그레이드 게임을 바탕으로** 원래 있던 괴물 8종의 입체 외형을 새로 제작해 게임 내 호출에 연결한 버전입니다. 기존 음악 9곡·효과음 56개와 수학 문제, 맵, 이동, 괴물 AI 판정은 그대로 보존했습니다.

## 이번 버전에서 교체한 모델

| 괴물 | 새 외형 및 움직임 | 실제 게임 이벤트 |
|---|---|---|
| 러쉬 | 불규칙한 검은 연기 덩어리, 여러 붉은 눈, 입속 이빨, 회전 광륜 및 부유 움직임 | 기존 복도 돌진·되돌아오기 유지 |
| 스크리치 | 어두운 얼굴, 빛나는 눈, 독립 촉수 7개, 부유·움찔 동작 | 기존 손전등 조준·흔들기 퇴치 유지 |
| 듀프 | 가짜 문 뒤 그림자 얼굴, 갈라진 눈, 길고 날카로운 손톱 | 기존 오답 문 기습·넉백 유지 |
| 앰부쉬 | 연녹색 귀신 형상, 뒤틀린 입, 유령 조각과 빛나는 윤곽 | 기존 여러 번 왕복하는 행동 유지 |
| 시크 | 반사되는 검은 신체, 단일 눈, 유기적인 팔·다리 | 기존 달리기·장애물 추격 유지 |
| 피규어 | 눈 없는 머리, 길게 벌어진 입, 늑골, 관절이 있는 팔다리 | 기존 소리 감지·웅크리기 대응 유지 |
| 잭 | 부피감 있는 후드, 골면 마스크, 움푹 파인 눈과 이빨, 움직이는 그림자 가닥 | 기존 옷장 깜짝 등장 유지 |
| 하이드 | 반투명 그늘 형상과 붉은 눈 | 기존 장시간 은신 시 밀어내기 유지 |

개선된 모델은 **2D 스프라이트나 화면에 붙이는 그림이 아닌, Three.js가 생성하는 실제 입체 메쉬**입니다. 기존 코드의 `build3D...Monster()` 함수는 동일한 이름을 유지하고, `MathDoorsMonsters.create(...)`를 호출하도록 변경했습니다. 주요 충돌 판정과 AI 타이밍은 기존 코드 그대로입니다.

## 확인실 및 파일

- `index.html` — 게임 실행
- `monster_gallery.html` — 8종 몬스터의 3D 회전 미리보기. 모델 버튼 선택 → 마우스/터치 드래그 회전, 휠로 확대
- `3d_asset_gallery.html` — 1차 가구·문·서랍 3D 에셋 확인실
- `assets/js/monster-models-v2.js` — 신규 입체 모델과 짧은 시각 애니메이션 생성 코드
- `assets/js/procedural-props.js` — 1차 실내 입체 가구 모델
- `assets/js/audio-manager.js` — 오디오 재생 관리자
- `assets/audio/bgm/` 9곡, `assets/audio/sfx/` 56개
- `tests/` — 모델 API 계약 검사 및 HTML·에셋 경로 검사

## 테스트 결과 및 제한

- Node.js 자바스크립트 구문 검사 완료.
- 8종 몬스터 생성 및 AI 연결에 필요한 노드 이름 테스트 통과.
- 게임 HTML·확인실·오디오 경로 검사 통과.
- **WebGL 전체 화면 렌더링과 실제 게임 플레이는 실행 환경에서 외부 Three.js CDN 접속이 불가능해 종합 검증하지 못했습니다.** 모델의 최종 시각 품질, FPS, 모바일 성능과 실제 피격/은신 타이밍은 GitHub Pages 배포 후 테스트가 필요합니다.
- 기존 AI는 그대로 유지했으며, 몬스터 외형이 개선됐다고 새로운 AI 행동을 구현한 것으로 주장하지 않습니다.
- 독창적 모델이며 원작 게임의 공식 3D 모델 파일을 사용하지 않았습니다.

## 간단한 GitHub 업로드

압축을 해제한 후 `index.html`, `monster_gallery.html`, `assets/` 등 내용물을 GitHub 저장소의 최상위에 올린 뒤 Settings → Pages에서 `main` / `(root)`를 지정하세요. 폴더째가 아닌 **폴더 내부 파일과 폴더를 루트에 올려야** 정상 동작합니다.

게임: `https://아이디.github.io/저장소명/`  
괴물 확인실: `https://아이디.github.io/저장소명/monster_gallery.html`

**인터넷 연결 필요:** Three.js와 Tailwind CSS를 CDN에서 불러오는 기존 구조는 변경하지 않았습니다.

# MATH DOORS — GitHub Pages 배포용 프로젝트

첨부된 Gemini 게임 `index(8).html`을 바탕으로, **게임 구조는 유지**하고 별도로 제작한 오리지널 BGM 9곡과 효과음 56개를 연결했습니다.


## 업데이트: 입체 3D 에셋 1차 적용

이번 버전에는 그림을 벽에 붙이는 방식이 아니라 Three.js로 **진짜 입체 메쉬를 생성하는 코드** `assets/js/procedural-props.js`를 추가했습니다. 외부 `.glb` 모델 파일을 다운로드하지 않아도 게임 실행 시 모델이 생성됩니다.

적용된 변경사항:

- **서랍장:** 입체 구조·안쪽 수납 공간·앞으로 슬라이드하는 서랍·손잡이·아이템 실물 형상
- **양문 옷장:** 문짝 몰딩·양쪽 회전 경첩·옷걸이 및 내부 공간·조명에 반응하는 목재
- **문·문틀:** 입체 테두리·장식 패널·양면 마감 및 브라스 손잡이
- **도서관:** 직육면체 한 장이 아닌 실제 선반과 개별 책으로 이루어진 3D 책장
- **창고:** 널빤지와 대각 지지대가 있는 3D 상자
- **퍼즐 단말기:** 숫자 키패드와 입체 제어 단말기
- **다리:** 기본 파란색 직육면체를 판자·난간·금속 고정못이 있는 목제 다리로 교체. 기존 정답 시 확장 애니메이션과 결합
- **원형 잠금장치:** 기어형 메쉬로 교체하고 정답 시 문 위로 떠오르는 대신 아래로 물러나도록 변경
- **객실·중앙 홀·암실:** 테이블·꽃병·시계·스탠드 등 소품 및 입체 하단 벽 몰딩 추가
- **충돌 판정:** 추가 가구 주변의 기존 원형 충돌 시스템에 맞춘 충돌체 추가
- **성능:** 일부 동일 크기의 3D 기하와 재질 공유, 고해상도 화면의 픽셀 비율 상한 1.5로 조정

`3d_asset_gallery.html`은 **3D 모델 확인실**입니다. GitHub Pages 배포 후 별도로 열어 모델을 드래그해 회전하고, 옷장·서랍이 열리고 닫히는 모습을 볼 수 있습니다.

예: `https://사용자명.github.io/저장소명/3d_asset_gallery.html`

### 기능 및 테스트 범위

게임 구조(6학년 수학 문제, 괴물 AI, 오디오, 조작)는 원칙적으로 그대로 유지했습니다. 자바스크립트 구문 검사 및 새 3D 모델 생성 함수의 부품별 테스트를 수행했습니다. 다만 이 제작 환경에서는 로컬 브라우저 페이지 접속이 차단되어 **게임 전체 실시간 실행/충돌 판정의 종합 플레이 테스트는 완료하지 못했습니다.** GitHub Pages 배포 후 PC와 모바일에서 문, 옷장 숨기, 서랍 아이템, 다리 이동, 도서관, FPS를 확인해 주세요.

`.glb` 파일과 달리 이번 에셋은 자바스크립트가 생성하는 입체 모델이며 게임 내에서 회전·열림·움직임이 가능합니다. 개별 3D 모델 파일(.glb/.fbx)로의 변환이 필요한 경우에는 추가 작업이 필요합니다.

## GitHub에 업로드하는 방법

1. GitHub에서 새 공개 저장소(Repository)를 생성합니다.
2. 이 ZIP을 풀어 나타나는 **`index.html`, `assets` 폴더 등 모든 파일과 폴더**를 저장소의 루트에 업로드합니다. ZIP 파일만 올리면 게임이 실행되지 않습니다.
3. `Settings → Pages → Build and deployment → Deploy from a branch`를 선택하고 `main / (root)`를 선택합니다.
4. 저장 후 표시되는 `https://계정명.github.io/저장소명/` 주소에서 실행합니다.

**참고:** 이 게임 HTML은 원래 `three.js` 및 Tailwind CSS를 외부 CDN에서 불러옵니다. 게임 플레이에 인터넷 연결이 필요하며, 네트워크에서 CDN 접속이 차단되면 3D 화면이 안 나올 수 있습니다. GitHub Pages의 기본 HTTPS 환경을 권장합니다.

## 이번에 반영한 내용

- 기존의 오실레이터 기반 단순 BGM·효과음을 실제 녹음/합성 오디오 에셋으로 연결
- 로비, 탐험, 수학 퍼즐, 암실, 러쉬/앰부쉬, 시크 추격, 도서관 피규어, 듀프, 게임 클리어용 BGM 자동 전환

- 게임에 이미 있던 `playSfx()` 호출을 56개 효과음으로 연결 (매핑되지 않은 파일은 추후 추가 이벤트에서 활용 가능)
- 로비와 인게임에서 🎚️ 버튼으로 **BGM / 효과음** 볼륨 분리 조절
- 음소거 설정 및 볼륨은 브라우저 저장소에 저장
- 중복 발소리 과다 재생 방지, 브라우저 탭 비활성화 시 BGM 일시 정지
