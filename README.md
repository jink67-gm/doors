## 1. GitHub Pages 업로드 방법

1. ZIP을 풀면 `index.html`, `assets/`, `tests/` 등이 나옵니다.
2. GitHub 저장소에 **폴더째가 아니라 안의 파일과 폴더를 저장소 맨 위(root)에** 올립니다. (`index.html`이 저장소 첫 화면에 보여야 합니다.)
   - 기존 V4 저장소라면 같은 이름 파일은 덮어쓰고, 새로 생긴 `assets/js/v5-core.js`, `assets/js/math-bank-v5.js`, `assets/vendor/three.min.js`, `assets/css/tailwind.css`도 꼭 올리세요.
   - 웹에서 올릴 때: 저장소 → **Add file → Upload files** → 압축 푼 폴더 안의 모든 항목을 끌어다 놓기 → Commit.
3. **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`** → Save.
4. 1~2분 뒤 `https://계정명.github.io/저장소명/` 로 접속합니다.
   - 괴물 확인실: `.../monster_gallery.html`, 가구·문 확인실: `.../3d_asset_gallery.html`

**V5부터 인터넷 CDN이 없어도 실행됩니다.** Three.js r128(MIT 라이선스)을 `assets/vendor/`에 넣었고, Tailwind CSS는 미리 빌드한 `assets/css/tailwind.css`를 씁니다. (학교망에서 CDN이 막혀 화면이 안 나오던 문제 대비. 글꼴만 Google Fonts에서 받고, 막히면 기본 글꼴로 표시됩니다.)
`file://`로 더블클릭해 열면 브라우저 보안 때문에 일부 소리·저장이 막힐 수 있으니 GitHub Pages 주소로 실행하세요.

## 2. V5 변경 내용

### ① 진행 불가능한 랜덤 맵 제거 (`assets/js/v5-core.js`)
- 방을 만들기 전에 **배치도(벽·칸막이·가구·장치·장애물의 충돌 영역)**를 먼저 만들고, 같은 충돌 함수로 **격자 경로 탐색**을 해서 다음을 모두 통과해야만 방을 만듭니다. 하나라도 실패하면 다른 시드로 **자동 재생성**합니다.
  - 장치 해결 전: 입구에서 단말기·모든 서랍·모든 옷장·열쇠 서랍·비밀방에 실제로 걸어갈 수 있는지
  - 장치 해결 후: 입구 → 출구 경로가 있는지 (다리·석상·관문 상태 반영)
  - 가구/구조물 겹침, 벽 속 가구, 절벽 위 물체, 공중에 뜬 책장·상자 금지
- **열쇠는 열쇠 탐색실에만**, 잠긴 문·절벽 뒤에는 절대 생기지 않음. 열쇠 탐색실과 다리 복구실은 서로 다른 방 종류라 겹치지 않음.
- **끊긴 다리 방**: 옷장·서랍 없음, 러쉬·앰부쉬 없음, 제어판은 항상 절벽 앞.
- **피규어 도서관 책장을 바닥(y=0)에 배치** (V4는 1.8 m 공중에 떠 있었음). 책장 사이 통로는 플레이어와 피규어(반지름 0.5 m) 모두 지나가도록 검사.
- **넉백이 벽을 뚫지 않음**: 이동과 넉백을 0.12 m 단위로 나누어 충돌을 계산합니다. 초속 25 m 넉백 시험에서도 벽·절벽·맵 밖으로 나가지 않습니다. 지나온 방으로 되돌아 밀려나지도 않습니다.
- **방을 나와 뒤돌아봐도 벽이 뚫려 있지 않음**: 듀프 방의 가짜 문 뒤 감실을 방 안쪽(문 평면 뒤 0.9 m)으로 옮겨 다음 방으로 튀어나오던 검은 상자를 없앴습니다. 지나온 방 1개는 그대로 보이고, 2개 이상 지난 방은 메모리에서 해제합니다.

### ② 10·20·30문 이벤트 스케줄 (`planStage`)
- 방을 만들기 전에 **스테이지 전체 계획**을 먼저 세우고 그 계획대로 방을 만듭니다. 한 방 번호에는 한 가지 특수 이벤트만 → V4에서 10문 모드의 4번 방이 시크에게 덮여 다리 방이 사라지던 문제 해결.
- 10문: 듀프·다리·열쇠·암실·시크·도서관(중간·최종)을 모두 압축 경험 (특수 방은 최대 2개까지만 연속).
- 20문/30문: 듀프·다리·열쇠 방 2개/3개씩, 시크 1회/2회, 같은 종류는 3문 이내 반복 금지, 특수 이벤트끼리 붙지 않게 배치.
- 시크·도서관 바로 다음 방에는 러쉬·앰부쉬가 없고(회복 방), 러쉬·앰부쉬는 연속된 방에 나오지 않습니다.

### ③ 듀프 방
- 단원 선택과 상관없이 모든 단원에서 **3개의 보기(정답 1, 오답 2)**를 만들 수 있어 항상 **같은 3D 모델의 문 3개**가 생깁니다.
- 가짜 문 → 듀프 등장 → 공격·넉백 → **문이 다시 닫힘** → 남은 문으로 재도전. **V5.1부터 듀프 공격은 다른 괴물과 같이 생명 1칸을 깎고, 0이 되면 사망**합니다. (퍼즐 화면에서 답을 틀린 경우만 마지막 1칸을 남깁니다.)
- 문 사이·옆 벽과 감실 천장을 막아 뚫린 곳이 없게 했습니다.

### ④ 수학 문제은행 (`assets/js/math-bank-v5.js`)
- V4의 고정 문항(선 잇기 답 "6"이 두 개, 쌓기나무 앞/옆 그림과 정답 불일치, 비교 그림이 정답 높이 노출 등)을 **매개변수형 생성기**로 바꿨습니다. 6개 단원 × 유형(A 선 잇기, B 빈칸, C 카드 배치/입체 분류, D 3×3 쌓기나무, E 듀프 문, F 장치 입력).
- 정답은 **분수 계산(분자/분모)**으로 구해 소수 오차가 없습니다. 입력은 값이 같으면 인정합니다(2/4 = 1/2 = 0.5).
- 한 판 안에서 **문제 ID·숫자 구성이 겹치지 않습니다**. 단원을 하나만 골라 30문을 해도 매번 새 숫자로 생성합니다.
- 지문은 짧게: 예) `3 : 4 = 15 : □`, `4.8 ÷ 0.3 = □`, `반지름 6 cm인 원의 넓이는 □ cm² (원주율 3.14)`.
- 선 잇기 오른쪽 보기에는 **값만** 표시(계산식 노출 금지), 세 값은 모두 다름.
- 쌓기나무(D): 위에서 본 자리·앞·옆 모양·총개수만 보여 주고 **정답이 하나뿐인 문제만** 출제. 목표 높이는 어디에도 그리지 않고, 학생이 쌓은 모양만 등각 그림으로 보여 줍니다.
- 옷장 걸쇠·심장박동 문제도 **선택한 단원에서만** 출제(V4는 모든 단원에서 출제).
- 학생 조작이 3D 장치로: 비례배분 다리(두 판이 비율대로 차례로 펼쳐짐), 원 잠금장치(회전·하강), 석상(옆으로 이동해 출구 개방), 쌓기나무 받침(맞힌 모양대로 블록이 솟음), 입체 분류 장치(원기둥·원뿔·구가 내려앉음).
- 세로 분수 표기, 반지름·지름·원주·원주율 용어 유지. 숫자 뒤 조사(을/를)가 틀리지 않도록 문장을 다듬었습니다.

### ⑤ 다양한 방 구조
객실, 화물 창고, **가운데 장애물이 있는 홀**, **ㄱ자 굴절 복도**(막힌 곁방 + 옆 통로), **ㄷ자 굽은 복도**(칸막이 지그재그), **지름길·우회로**(웅크려 지나는 낮은 구멍 vs 돌아가는 길), **비밀방이 있는 별관**(좁은 틈, 회복약·배터리), **열쇠 탐색 곁방**, 암실, 듀프 갈림길, 끊어진 다리, 시크 복도, **돌아가는 도서관 통로**. 방 크기는 18~28 m(시크 복도 44 m)로 이동만 길어지지 않게 했습니다. 벽 장식(조명·액자)은 가구와 겹치지 않는 자리에만 붙습니다.

### ⑥ 괴물 행동
- **피규어**: 발소리 반경(걷기 7.5 m / 웅크려 걷기 2.2 m), **바로 곁(약 2.3 m)에서는 웅크려도 감지**, **삐걱이는 마룻바닥(약간 밝은 판자)**은 웅크려도 9 m까지 들림, 서랍 여는 소리도 들림. 격자 경로로 책장을 돌아 다니고 매 프레임 충돌 보정으로 책장을 통과하지 않음. 들킨 채 옷장에 숨으면 피규어가 옷장 앞으로 와서 **심장박동 문제** 시작 → 정답 전에는 떠나지 않음(오답 2번마다 옷장을 내리쳐 생명 −1, 마지막 1칸은 유지) → 정답 직후 6초 안전 시간 후 순찰 복귀.
- **시크**: 44 m 추격 유지. **플레이어가 지나간 발자국을 따라와서** 벽·장애물을 통과하거나 순간이동하지 않습니다(V4의 "잡히면 5.5 m 뒤로 순간이동" 제거 → 잠시 멈칫). 낮은 기둥 2개는 웅크려 통과, 중간 관문의 **불 켜진 문**만 열리고 어두운 문은 잠겨 흔들림(재도전 가능). 화살표 없이 출구 조명·문 위 등불로 길 안내.
- **러쉬·앰부쉬**: 접근·통과·되돌아옴 효과음을 실제 위치에 맞춰 재생. 러쉬·앰부쉬가 나오는 방은 앞쪽·뒤쪽에 옷장이 하나씩 있고, 방 어디서든 옷장까지 걸어서 17.5 m 이내인 것을 검사합니다.
- **하이드**: 앰부쉬가 왕복·정지하는 동안, 위험이 끝난 직후 4초, 심장박동 중에는 밀어내지 않음.
- 시크에게 잡히면 4초, 잠긴 문을 민 직후 1.5초 동안은 다시 잡히지 않아 연속 피격으로 한꺼번에 생명을 잃지 않습니다.
- **연속 정답 3회마다 생명 +1** (오답으로 생명 1까지 떨어져도 회복할 수 있음).
- 스크리치(손전등 비추고 흔들기), 잭, 듀프는 기존 방식·외형 유지. 경고는 전등 깜빡임·소리·짧은 자막·**청각 보조 신호(아이콘 + 화면 가장자리 빛)**로 전달합니다.

### ⑦ 체크포인트·이어하기
- **DOOR 5, 10, 15 … 에 들어갈 때 자동 저장**(localStorage, 서버 없음). 로비에 **새 게임 / 이어하기 / 저장 기록 삭제(두 번 누르기)**. 사망 화면에도 "체크포인트에서 이어하기".
- 저장 내용: 시드, 문 번호, 단원, 난이도, 생명, 단서 쪽지, 회복약, 배터리, 해결한 퍼즐 수, 방어 문제 출제 이력, 이전 방 문제 기록(검증용).
- 같은 시드로 방 배치·문제를 다시 계산하므로 **새로고침 후에도 같은 방 구조·같은 문제**, 바로 앞 방은 **문이 열린 상태**로 복원됩니다.
- 손상·구버전·불일치 저장 데이터는 무한 로딩 없이 정리하고 로비로 돌아갑니다.

### ⑧ 성능·모바일·접근성
- 현재 방 앞뒤 1칸만 렌더링, 2칸 이상 지난 방은 해제. 재질·기하 공유, 책장의 책을 **InstancedMesh**로(책장당 100여 개 → 7개 그리기 호출).
- 방마다 조명 수를 2개로 고정하고 괴물 몸빛은 공유 조명 1개로 대체 → 괴물이 나타날 때 셰이더 재컴파일로 멈칫하던 현상 방지.
- 터치 기기·저사양은 안티에일리어싱 끔, FPS가 낮으면 해상도 배율 자동 하향(0.65까지).
- 근접 버튼은 내용이 바뀔 때만 화면 갱신(매 프레임 DOM 수정 제거).
- 모바일: 조이스틱(왼쪽)과 시점 회전(오른쪽 드래그)은 서로 다른 손가락으로 동시에 가능. **퍼즐·긴급·심장박동 창이 열리면 이동·시점 입력을 잠그고 조이스틱·회전 버튼을 숨겨** 입력창과 겹치지 않음. 닫으면 정상 복귀.
- 손전등은 시작 시 OFF, 어두운 방에서만 한 줄 안내, 배터리 소모와 15% 경고음 유지. BGM·효과음 개별 볼륨/음소거, 흔들림·번쩍임 완화 유지.

## 2-1. 오디오 업데이트 (2026-10-22)
- **BGM 9곡 교체**: 받은 오디오 팩의 `assets/audio/bgm/` 9곡(각 42~51초 루프)으로 바꿨습니다. 로비 `01` / 탐험 `02` / 수학 퍼즐 `03` / 암실 `04` / 러쉬·앰부쉬(옷장 대기 포함) `05` / 시크 `06` / 피규어 도서관 `07` / 듀프 `08` / 탈출 성공 `09`.
- **새 재생 방식(Web Audio)**: 곡을 미리 디코딩해 **이음새 없이 반복**하고(브라우저 디코더가 붙이는 앞뒤 무음 자동 제거), 상태가 바뀌면 **1.2초 크로스페이드**. 같은 곡이면 다시 시작하지 않습니다. Web Audio가 없는 브라우저는 예전 방식(HTMLAudio)으로 재생합니다.
- **자동재생 차단 대응**: 첫 클릭·터치·키 입력 전에는 아무 소리도 재생하지 않아 브라우저 오류가 나지 않습니다. 첫 입력에 로비 음악, **새 게임 시작 클릭**에 탐험 음악이 시작됩니다. 탭을 숨기면 일시정지, 돌아오면 재개.
- **발소리 새로 구성**: 옛 합성 발소리와 예전 발소리 호출을 제거하고, `footstep_{표면}_{walk|crouch|run}_NN.mp3`에서 **무작위 재생(같은 파일 연속 금지)**.
  - 표면: 객실·복도의 **가운데 붉은 카펫 띠 = carpet**, 띠 바깥·도서관 가장자리·다리 상판·삐걱 마루 = **wood**, 중앙 장치 홀·시크 복도 = **stone**(돌 타일 바닥으로 그림도 변경), 화물 창고 = **metal**(철판 바닥으로 그림도 변경).
  - 간격: 걷기 0.46초, 웅크려 걷기 0.72초, 달리기 0.33초(시크·러쉬·앰부쉬·피규어에게 쫓길 때 빠르게 이동하면 달리기 소리). 조이스틱을 덜 기울이면 간격이 길어집니다.
  - **멈추면 즉시 발소리 정지**(남은 소리도 짧게 끊음), **웅크리기 전환 자체는 무음**, 옷장·퍼즐 창에서도 정지.
  - 플레이어 발소리만 예전보다 **낮게(걷기 0.30 / 웅크림 0.14 / 달리기 0.42)**, 저역 필터(3.2 kHz)로 **부드럽게**.
- **BGM / 효과음 슬라이더는 서로 독립**(설정은 브라우저에 저장). 괴물 경고음 등 기존 효과음 54개는 모두 그대로이고, 그동안 연결되지 않았던 5개(옷장 진입·문 잠금·피규어 냄새·하이드 숨소리·시크 발걸음)도 키에 연결해 두었습니다.

> ⚠️ **발소리 44개는 임시 음원입니다.** 받은 폴더(`최종본/MATH_DOORS`)에는 BGM 9곡만 있고 `footstep_*` 파일과 `audio-manager-V4-호환_선택적교체.js`가 없었습니다. 그래서 요청한 파일명 그대로 발소리를 직접 합성해 넣었습니다(카펫=부드럽고 둔함, 나무=따뜻한 울림, 돌=짧고 단단함, 금속=울리는 소리). **원본 오디오 팩의 같은 이름 파일을 `assets/audio/sfx/`에 덮어쓰면 코드 수정 없이 바로 바뀝니다.** V4 참고 JS는 받지 못해 비교·병합하지 못했습니다.

## 2-2. V5.1 — 학생 피드백 반영 + 그래픽 품질 (2026-10-30)
**괴물·하이드 수정**
- **러쉬·앰부쉬가 다음 방까지 따라옴**: 경고(깜빡임·소리)나 돌진 중에 문을 넘으면 괴물이 사라지지 않고 **다음 방까지 이어서 휩쓸고 지나갑니다**. 깜빡임도 플레이어가 있는 방에서 계속되고, 따라온 방에서는 새 러쉬·앰부쉬·스크리치를 겹쳐 부르지 않습니다.
- **숨을 곳이 없는 다음 방이면 문이 막힘**: 다음 방이 도서관·시크 복도·끊어진 다리(옷장 없음)이거나 마지막 문이면 "문 너머에는 숨을 곳이 없다… 이 방 옷장에 숨어야 한다!" 안내와 함께 문 앞에서 밀려납니다. 괴물이 지나가면 다시 열립니다.
- **앰부쉬 중 하이드 등장**: 왕복 사이 쉬는 시간을 1~1.6초 → **쉬움 6~7초 / 보통 5~6초 / 도전 4.3~5초**로 늘렸습니다. 쉬는 동안 옷장에 계속 있으면 **약 1초 뒤 하이드가 깨어나 두드리고(👀) 2.3초(쉬움 2.6 / 도전 2.0)에 밀어냅니다.** 밀어낼 때는 **피해 없음**, 쉬는 시간마다 한 번만 밀고, 앰부쉬가 돌아오기 전까지 약 3초 안에 다시 숨으면 안전합니다. 앰부쉬가 실제로 지나가는 순간에는 하이드가 밀지 않습니다.
- **듀프 공격 = 생명 −1, 0이면 사망** (생명 2에서 가짜 문 두 번이면 게임 오버).

**그래픽 품질 (도형이 딱딱해 보이는 문제)**
- **둥근 모서리**: 옷장·서랍장·탁자·문틀·상자 등 소품 조각(두께 4 cm 이상)을 모서리가 둥근 상자로 바꿔 빛이 모서리를 타고 흐릅니다. 침대는 매트리스·베개·담요까지 둥글게.
- **텍스처**: 벽지(다마스크 무늬·물 얼룩·천장 쪽 그늘) + 나무 징두리 판벽, 엇갈린 나무 마루 + 테두리·무늬·닳은 자국이 있는 카펫, 돌 타일 얼룩·금, 철판 녹, 격자 천장. 소품에는 나뭇결·직물·금속 결. 모두 캔버스로 만들어 **추가 파일 다운로드 0**.
- **빛**: 영화용 톤매핑(ACES) + 위·아래 색이 다른 반구광으로 평평한 주변광을 대체, 벽·바닥 요철(범프).
- **접지 그림자**: 가구·장치 밑 부드러운 그림자와 벽-바닥 모서리 그늘(방마다 메쉬 2개로 합쳐 그리기 → 그리기 호출 +2).
- **분위기**: 떠다니는 먼지, 아주 옅은 필름 그레인(흔들림 완화 켜면 정지).
- **🎨 그래픽: 고품질 / 가볍게** 버튼(로비): '가볍게'는 요철·먼지·그레인을 끕니다. 터치 기기·저사양은 처음부터 '가볍게', 고품질에서 화면이 계속 느리면(해상도를 최저로 낮춘 뒤에도 26 fps 미만) 자동 전환합니다. 선택은 브라우저에 저장됩니다.
