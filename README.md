# MATH DOORS — V4 대형 맵 / 피규어 도서관 업데이트

기존 V3(잔잔한 BGM·3D 괴물/가구)에 이어 **맵·도서관·추격 동선·가구 겹침**을 수정한 버전입니다. 새 게임이 아니라 V3의 게임 코드를 기반으로 합니다.

## GitHub Pages 배포

1. `MATH_DOORS_V4_맵확장_피규어수정_GitHub용.zip`을 내려받아 압축을 해제합니다.
2. 압축을 푼 내부 내용(`index.html`, `assets/`, `*.html`, `.nojekyll`)을 기존 GitHub 저장소의 **최상위**에 올립니다. **ZIP 자체만 올리는 방식은 안 됩니다.**
3. `Settings → Pages → Deploy from a branch → main / (root)`로 설정합니다.
4. `https://<계정>.github.io/<저장소>/`로 실행합니다. 로컬 HTML을 더블클릭하면 일부 오디오가 차단될 수 있으므로 GitHub Pages 또는 로컬 웹 서버가 좋습니다.

## 주요 변경점

| 대상 | 이전 | V4 |
|---|---|---|
| 피규어 도서관 | 폭 18m, 길이 26m; 떠 있는 책장 | **폭 30m, 길이 62m**, 책장 지면 고정, 경량형 책장 12개, 우회 장애물 5개 |
| 피규어의 추적 | 웅크리면 소음이 적어 회피가 지나치게 쉬움 | 순찰 동선 6개 구간, **삐걱이는 마룻바닥 3곳**, 가까이 다가가면 웅크린 상태도 발견될 수 있음 |
| 피규어 옷장 | 들킨 뒤 숨으면 추적이 자동으로 풀림 | **심장박동 수학 퀴즈**: 정답이면 진정·순찰 복귀, 오답/시간초과면 옷장에서 피격·탈출 재도전 |
| 끊긴 다리 구역 | 다리 양쪽 옷장 생성, 다리 앞 서랍 | **옷장·서랍 없음, 러쉬·앰부쉬 등장 안 함**, 다리 복구 후 이동 |
| 열쇠와 다리 | 간혹 열쇠 방과 다리 퍼즐이 같은 방에 겹침 | 두 개의 방 유형을 분리하여 **열쇠가 끊긴 다리 뒤에 나타나지 않게 처리** |
| 시크 추격 | 길이 38m, 장애물 2개 | **길이 94m(2.47배)**, 좌우 장애물 7곳·낮은 구조물 2곳, 시크 접근 속도 소폭 조절 |
| 듀프 오답 문 | 생명력이 낮으면 오답 한 번으로 종료될 수 있음 | 오답 문은 계속 기습·넉백, **최소 1 생명은 남겨 재도전 가능** |
| 일반 방 | 대부분 폭 13~18m, 길이 20~25m | 방 유형별 폭 17~22m, 길이 28~40m, 무작위 약 ±7% 크기 차이 |

**새로운 심장박동 퀴즈**는 기존 게임의 `DEFENSE_MATH_BANK`에서 중복 기록을 관리하며 출제합니다. 정답이면 피규어 경계 상태가 해제됩니다. 실패해도 초등학생 학습 게임 특성상 무조건 즉사하지 않습니다. 기존 음악 9곡·효과음 56개를 유지하고 `ambient_heartbeat.mp3`를 이 이벤트에 추가 연결했습니다.

## 실제 플레이 확인 순서

1. **10/20/30문** 설정마다 시작하고, 중간 도서관에 입장하여 책장이 바닥에서 뜨지 않는지 확인합니다.
2. 도서관에서 웅크려 이동하고, 일부 마룻바닥이 삐걱거리면 피규어가 조사하러 오는지 확인합니다.
3. 들킨 뒤 옷장으로 이동하여 **심장박동 문제**를 맞힙니다. 피규어가 가까이 기다리다 다시 순찰로 돌아가야 합니다. 문제를 틀리면 피격 이후 다시 달아날 수 있어야 합니다.
4. 다리 구역에는 옷장도, 열쇠 서랍도 없어야 하며 러쉬가 등장하지 않아야 합니다. 장치를 해결한 뒤 다리를 건너갑니다.
5. 시크 추격 구간에서 길이가 이전보다 2배 이상 긴지, 장애물이 번갈아 나타나는지, 출구로 진입 가능한지 확인합니다.
6. 듀프 오답 문을 열어도 정답 문이 사라지지 않아야 하고 피격 후 재시도가 가능해야 합니다.
7. 반복 테스트에서 이동 막힘, UI 중복, 지나친 프레임 저하가 없는지 확인합니다.

## 기술 및 검증

- `index.html`: 3D 공간, 몬스터·문·퍼즐 로직, 피규어 심장박동 UI
- `assets/js/procedural-props.js`: 도서관용 경량 3D 책장
- `assets/js/audio-manager.js`: 심장박동 효과음 연결
- `assets/audio/bgm/`: MP3 9곡
- `assets/audio/sfx/`: MP3 56개
- `tests/v4_contract_test.py`, `tests/bridge_safety_test.py`: 정적 구조/안전 검사
- `tests/monster_contract_test.js`, `tests/project_static_checks.py`: 모델 연결/오디오/문법 검사

**검증 범위:** 자바스크립트 문법, 모델 생성 계약, 오디오 개수·경로, 새 방 구조의 정적 조건 및 ZIP 무결성을 검사했습니다. 브라우저 접속이 실행 환경에서 차단되어 **실제 WebGL 렌더링과 게임 전체 플레이 테스트는 완료하지 못했습니다**. 위 체크리스트대로 GitHub Pages에서 확인해 주세요.

**주의:** 기존 프로젝트는 외부 Three.js 및 Tailwind CSS CDN을 사용하므로, 페이지 실행에는 인터넷 연결이 필요합니다.
